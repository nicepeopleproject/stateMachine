# State Machine Constructor / Конструктор машин состояний

Онлайн-конструктор для создания и редактирования шаблонов машин состояний на базе Jmix Framework.

Online constructor for creating and editing state machine templates built with Jmix Framework.

## Возможности / Features

- 🎨 **Визуальный редактор** - создание диаграмм состояний с графическим интерфейсом
- 📋 **CRUD операции** - полное управление шаблонами, состояниями и переходами
- 🔄 **Управление состояниями** - создание начальных и финальных состояний
- ➡️ **Переходы между состояниями** - настройка событий и условий для переходов
- 💾 **Хранение в БД** - все шаблоны сохраняются в базе данных (HSQLDB)
- 🌐 **Веб-интерфейс** - доступ через браузер
- 🇷🇺🇬🇧 **Мультиязычность** - поддержка русского и английского языков

## Технологический стек / Tech Stack

- **Jmix 2.2.3** - платформа быстрой разработки бизнес-приложений
- **Spring Boot 3.1.5** - фреймворк для разработки Java приложений
- **EclipseLink** - JPA провайдер для работы с базой данных
- **HSQLDB** - встроенная база данных
- **Liquibase** - управление схемой БД
- **Gradle 8.4** - система сборки

## Структура данных / Data Model

### Сущности / Entities

1. **StateMachineTemplate** - Шаблон машины состояний
   - `name` - название
   - `description` - описание
   - `initialStateId` - начальное состояние
   - `active` - активность шаблона
   - `states` - список состояний
   - `transitions` - список переходов

2. **State** - Состояние
   - `name` - название
   - `stateKey` - уникальный ключ
   - `description` - описание
   - `isFinal` - признак финального состояния
   - `positionX`, `positionY` - координаты для визуализации

3. **Transition** - Переход между состояниями
   - `name` - название
   - `fromState` - исходное состояние
   - `toState` - целевое состояние
   - `eventName` - событие-триггер
   - `conditionScript` - скрипт условия
   - `actionScript` - скрипт действия

## Использование / Usage

### Создание шаблона машины состояний

1. Откройте раздел "Application" → "Templates"
2. Нажмите "Create"
3. Заполните название и описание
4. Сохраните шаблон

### Добавление состояний

1. Откройте созданный шаблон для редактирования
2. Перейдите на вкладку "States"
3. Нажмите "Create"
4. Заполните:
   - Название состояния
   - Уникальный ключ (stateKey)
   - Отметьте "Final State" если это конечное состояние
   - Задайте координаты для визуализации (positionX, positionY)

### Добавление переходов

1. На вкладке "Transitions" нажмите "Create"
2. Выберите исходное и целевое состояние
3. Укажите событие (eventName)
4. Опционально: добавьте условия и действия (скрипты)

### Визуальный редактор

1. В списке шаблонов выберите нужный
2. Нажмите кнопку "Visual Editor"
3. Просматривайте диаграмму состояний с переходами
4. Нажмите "Refresh Diagram" для обновления визуализации
